
# FocusLock

### Earn Your Scroll. Master Your Goals.

FocusLock is a study and productivity app that helps you protect your attention with focus sessions, small learning quizzes, and encouraging breaks.

## Features

- Dashboard with today's focus time, completed sessions, quiz progress, and recent sessions
- Configurable Pomodoro focus and break timer with pause, resume, reset, and browser-local timer continuity
- Sample study quiz with answer explanations and saved scores
- Nova, a friendly study companion with a local, predefined-response chat demonstration
- Break activities with jokes, riddles, and encouragement
- A saved list of distracting websites and a clear explanation of the limits of website blocking
- SQLite persistence for timer preferences, website lists, completed sessions, and quiz scores

## Technology Stack

- React and Tailwind CSS (Vite development server)
- Python and FastAPI
- SQLite
- Google Gemma 4 and Chrome Extension APIs are not connected in this demonstration

## Run on Replit

Use the **Start application** workflow or run:

```sh
npm install
python3 -m pip install -r requirements.txt
npm run dev
```

The web app is served on port 5000. The FastAPI service runs on port 8000 and the Vite development server proxies `/api` requests to it.

## Demonstration notes

- The quiz questions are sample content; they are not generated by an AI model.
- Nova uses local predefined replies. No AI credentials are required, and no message is sent to an external model.
- The website list is saved as a personal settings list only. A regular web app cannot block other sites or apps on your device; device-wide blocking would require a separately implemented browser extension or other supported mechanism.
- The timer state is stored in this browser. Study statistics, quiz scores, timer preferences, and website settings are stored in the local SQLite database for this Replit app.
