
# FocusLock

### Earn Your Scroll. Master Your Goals.

FocusLock is an AI-powered productivity application that encourages users to learn before accessing distracting websites.

## Planned Features

- AI-powered quizzes using Google Gemma 4
- Focus sessions and study timer
- Learning assessment and feedback
- Reward system for completing learning goals
- Chrome extension for website blocking
- Study progress dashboard

## Technology Stack

- React
- Tailwind CSS
- Python
- FastAPI
- Google Gemma 4
- SQLite
- Chrome Extensions API
